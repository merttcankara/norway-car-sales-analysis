# Norway New Car Sales Analysis

## Project Overview

This project analyzes new car sales in Norway between 2007 and 2017 by brand and model. The main goal is to explore sales patterns, identify the best-selling brands and models, and practice data analysis using Python and Pandas.

## Dataset

The dataset contains new car sales records in Norway by year, month, brand, and model.

The dataset includes the following columns:

- `Year`: Year of the sales record
- `Month`: Month of the sales record
- `Make`: Car brand
- `Model`: Car model
- `Quantity`: Number of cars sold
- `Pct`: Market share percentage

The dataset contains 2,694 rows and 6 columns.

## Project Workflow

1. Loading the dataset
2. Inspecting data structure
3. Checking missing values
4. Cleaning brand and model names
5. Filtering data by brand and model
6. Analyzing total sales by brand
7. Analyzing total sales by model
8. Performing brand-specific analysis for Toyota and Audi
9. Sorting and ranking sales performance

## Analysis Questions

This project focuses on questions such as:

- Which car brands sold the most in Norway?
- Which car models had the highest total sales?
- How did Toyota models perform during the selected period?
- Which Audi models had the highest sales?
- How can sales data be grouped and summarized using Pandas?

## Key Findings

- Volkswagen had the highest total sales in the dataset.
- Toyota was one of the strongest-performing brands.
- Volkswagen Golf was one of the best-selling models.
- Pivot tables and grouped summaries helped identify brand and model-level sales performance.


## Files

- `norway_data.ipynb`: Main notebook containing the analysis.
- `norway_new_car_sales_by_model.csv`: Dataset used in the analysis.

## Conclusion

This project demonstrates basic exploratory data analysis skills using Python and Pandas. It focuses on cleaning, filtering, grouping, and summarizing car sales data to extract useful insights.
